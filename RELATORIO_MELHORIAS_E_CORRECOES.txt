1. DIAGNÓSTICO GERAL E PRINCIPAIS MOTIVOS DOS ERROS
====================================================================================================

Durante a auditoria completa, foram identificados 5 grandes padrões que causam falhas no sistema:

A. CRASH FATAL DE REACT (TELA BRANCA):
   - Na página de detalhes do projeto (ProjetoDetalhes.tsx), o banco de dados armazena `detalhes`
     como uma lista de objetos JSON: [{"titulo": "...", "conteudo": "..."}].
   - O componente tenta renderizar `{paragrafo}` diretamente como texto:
     `{projeto.detalhes.map((paragrafo) => <p>{paragrafo}</p>)}`
   - O React rejeita renderizar um objeto diretamente como filho, disparando o erro fatal:
     "Objects are not valid as a React child", fazendo a página crashar completamente em branco.

B. FALTA DE ATRIBUTOS NO SERIALIZADOR (to_dict) DO MODELO Project:
   - No arquivo `models.py`, o método `Project.to_dict()` não inclui o campo `tags`, nem os dados do
     `orientador`, nem `professor_id`.
   - Consequência: Em `Projetos.tsx`, a propriedade `p.tags` chega como `undefined`. A barra lateral
     de filtros fica 100% vazia ("Nenhuma tag cadastrada") e a busca por tags não funciona.

C. DISCREPÂNCIA ENTRE URLs DO FRONTEND E ROTAS DO FLASK (ERROS 404 E 405):
   - O frontend utiliza o Axios configurado com `baseURL: '/api'`.
   - Muitas rotas no Flask foram criadas sem o prefixo `/api` (ex: `/submissao`, `/admin/logs`,
     `/projeto/<id>/workspace`). Quando o frontend faz a requisição, ele busca `/api/admin/logs`
     ou `/api/submissao`, resultando imediatamente em erro 404 (Endpoint não encontrado).
   - O endpoint `/api/perfil/editar` no Flask foi registrado apenas como `methods=['PUT']`, mas o
     formulário React envia uma requisição `POST`, resultando em erro 405 Method Not Allowed.

D. ROTAS FLASK INTERCEPTANDO O ROTEAMENTO DO REACT (SHADOWING):
   - O Flask possui rotas como `@app.route('/coordenador')` e `@app.route('/submissao')`.
   - Se o usuário digita na barra de endereço `http://site/coordenador`, o Flask intercepta a rota
     antes do fallback do React SPA e retorna JSON puro ou redirect 302, impedindo o usuário de ver
     a interface da tela do React. Todas as rotas de dados devem ser `/api/...`.

E. TELAS COM DADOS "MOCK"/FAKES E BOTÕES MORTOS:
   - Páginas cruciais como `Workspace.tsx`, `AdminDashboard.tsx`, `CoordenadorDashboard.tsx`,
     `AdminLogs.tsx`, `CandidaturaEditar.tsx` e `SubmissaoEditar.tsx` possuem dados estáticos
     injetados com `useEffect` fake, e grande parte dos botões de ação ("Salvar", "Aprovar",
     "Rejeitar", "Excluir", "Exportar CSV") não têm evento `onClick` configurado.
